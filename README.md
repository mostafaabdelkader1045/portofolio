### Title
**Develop and Enhance Personal Portfolio Website**

### Description
Develop and enhance a personal portfolio website using Streamlit to present my professional profile, technical skills, experience, projects, education, and contact information.

### Requirements
- Create a professional and modern portfolio UI.
- Implement a consistent **Dark Navy & Blue theme**.
- Add a personal profile photo to the Hero section.
- Organize the portfolio into sections:
  - Hero / Introduction
  - About
  - Experience
  - Projects
  - Skills
  - Education
  - Services
  - Contact
- Improve the Contact section using interactive contact cards for Email, LinkedIn, GitHub, and WhatsApp.
- Add hover effects and responsive styling.
- Configure the Streamlit theme using `.streamlit/config.toml`.
- Ensure the website is properly structured and all images are displayed correctly.

### Tech Stack
- Python
- Streamlit
- HTML
- CSS

### Deliverables
- Complete working `app.py`
- Streamlit theme configuration
- Required assets and images
- Functional links to professional accounts
- Responsive and polished UI
